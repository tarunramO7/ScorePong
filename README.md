# ScorePong
The ultimate DIY digital scorer for your ping pong battles! Using a Raspberry Pi Pico, this project tracks and displays scores in real-time, making your table tennis games smarter and more fun. Whether you're playing competitively or casually, ScorePong adds that perfect tech twist.
