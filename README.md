# ScorePong
The ultimate DIY digital scorer for your ping pong battles! Using a Raspberry Pi Pico, this project tracks and displays scores in real-time, making your table tennis games smarter and more fun. Whether you're playing competitively or casually, ScorePong adds that perfect tech twist.

# Components
| Components | No. |
|---|---|
| Blue LEDs | 2 |
| Green LED | 1 |
| Red LED | 1 |
| Push Buttons | 2 |
| Breadboard | 2 |
| Jumper Wires | 12 |
| Raspberry Pi Pico | 1 |

# Connections
(as per Raspberry Pi Pico H 2021 Model)
| Components | Pin No. |
|---|---|
| Blue LED +ve (Player 1) | 1 |
| Blue LED +ve (Player 2 | 2 |
| Push Button Pin 1 (Player 1) | 4 |
| Push Button Pin 1 (Player 2) | 5 |
| Red LED +ve | 25 |
| Green LED +ve | 21 |
| Push Button Pin 3 (Player 1) | Any Ground |
| Push Button Pin 3 (Player 2) | Any Ground |
| Resistor (220 Ω) | Any Ground |
| LEDs -ve | Through Resistor |
